You are a senior solutions architect and software engineer.

Analyze the following Jira ticket and convert it into an implementation-ready engineering specification.

TICKET:
{paste ticket here}

OUTPUT FORMAT:

1. Summary
- What is being built?
- What business/user problem is being solved?

2. Workflow
- Step-by-step user/system flow
- Expected behavior
- Success/failure paths

3. Functional Requirements
- Explicit requirements from the ticket
- Inferred requirements (clearly labeled)

4. System Impact
- Backend impact
- Frontend/UI impact
- Database/model impact
- API impact
- Infrastructure/processing impact

5. Dependencies
- Internal dependencies
- External services
- Blocking items

6. Risks / Ambiguities
- Missing information
- Assumptions
- Potential implementation risks

7. Suggested Task Breakdown
- Backend tasks
- Frontend tasks
- Infrastructure tasks
- Processing tasks
- QA/testing tasks

8. Testing Strategy
- Unit tests
- Integration tests
- User validation flow

9. Open Questions
- Questions requiring stakeholder clarification

10. External Reference Patterns
- Search for similar implementation approaches or common industry patterns
- Clearly label these as “reference only”
- Do not assume they are correct for this system

IMPORTANT:
- Clearly separate facts vs assumptions
- Do not implement code
- Focus on making the task safe for parallel AI execution
